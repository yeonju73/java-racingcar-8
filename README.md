# java-racingcar-precourse

### 1. 자동차 이름 입력 기능

- 사용자로부터 경주에 참여할 자동차 이름을 쉼표(`,`)로 구분하여 입력받습니다.
- 입력된 각 이름이 **5자 이하**인지 검증합니다.

### 2. 시도 횟수 입력 기능

- 사용자로부터 경주를 몇 번 진행할지 시도 횟수를 입력받습니다.

### 3. 자동차 전진 또는 정지 기능

- 각 자동차는 0에서 9 사이의 무작위 값을 생성합니다.
- 생성된 값이 **4 이상이면 전진**하고, 3 이하이면 멈춥니다.

### 4. 경주 진행 및 결과 출력 기능

- 입력된 시도 횟수만큼 모든 자동차의 전진 또는 정지 과정을 반복합니다.
- 매 회차가 끝날 때마다 각 자동차의 이름과 현재까지의 전진 상태를 출력합니다. (예: `pobi : __`)

### 5. 최종 우승자 판별 및 출력 기능

- 경주가 모두 끝나면 가장 많이 전진한 자동차를 우승자로 선정합니다.
- 우승자가 한 명 이상일 수 있으며, 공동 우승자도 모두 출력합니다. (예: `최종 우승자 : pobi, jun`)

### 6. 예외 처리 기능

- 사용자가 자동차 이름 규칙(5자 이하)이나 시도 횟수(숫자) 등 잘못된 값을 입력하면 `IllegalArgumentException`을 발생시키고 프로그램을 즉시 종료합니다.
